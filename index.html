已完善的基础功能

🔧 驱动专区

聚合 48 条驱动源记录（Turnip / PanVK / Xclipse / 厂商系统），按 GPU 架构与成熟度分类，多来源自由切换。

🧩 组件专区

Wine / Proton、Box64 / FEXCore、DXVK / VKD3D-Proton 等转译组件，聚合多个上游目录，一键下载。

📦 运行库专区

VC++ 运行库、.NET、解码器、字体、DirectX 等 Winlator 常用依赖，附中文用途说明。

📱 按设备匹配

自动识别 GPU 型号与 Adreno / Mali 代际，驱动按匹配度排序推荐，可在设置关闭查看全部。

🚀 镜像加速

接入 MirrorHub 加速节点，自动测速选优，支持手动切换或直连。

💾 下载管理

断点续传、按类型分目录存放、扫描本地已有文件、查看包内 meta.json 信息。

🕹 模拟器聚合

收录 Winlator / Eden / Citron / GameHub / Sumi 等官方源，含稳定版与官方每夜构建源。

🌐 中英双语

简体中文 / English，设置内一键切换。

为什么选择 EmuBox

一站式资源管理

驱动、转译组件、运行库、模拟器源整合在单个 App，同类工具大多只单独管理模拟器。

GPU 智能筛选

自动识别 SoC GPU，过滤不匹配驱动，减少无效查找（骁龙用户可隐藏 Mali 分区）。

信息透明

多源切换展示仓库更新时间与 Star，来源可追溯。

开源可审计

MIT 协议，正式签名稳定版，无广告，无账号要求。
